# 青蛙公主

暗黑水墨风 2D 横版动作 RPG（Phaser 3 + Vite）。

## 运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
# 产物在 dist/，可直接静态部署
```

## 操作

| 键 | 作用 |
|----|------|
| A/D 或 ←/→ | 移动 |
| W / ↑ / 空格 | 跳跃（二段跳） |
| J / 鼠标左键 | 攻击（城堡战） |
| E | 采集灵芝 / 对话 |
| Q | 使用灵芝回血 |
| Shift | 金蟾脱壳冲刺（逃生） |
| 空格 / Enter | 推进对话 |

## 五幕流程

1. 王宫悬赏 → 2. 绝望沼泽 → 3. 恶龙城堡（杀龙/质问）→ 4. 复仇逃生 → 5. 终局
